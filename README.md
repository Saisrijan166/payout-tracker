# Meme'd Campaign Payout Tracker

Brands create campaigns with a milestone payout ladder and a fixed budget; creators submit posts and get paid as their views cross milestones.

- `backend/`: Node.js, TypeScript, Express 5, MongoDB (Mongoose)
- `frontend/`: Next.js, TypeScript

Setup instructions are added as the project is built. See `IMPLEMENTATION_PLAN.md` for the build plan.
